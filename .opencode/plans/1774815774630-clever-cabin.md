# Chat Application Core Features Plan

## Scope

Implement database schema and REST APIs for real-time chat (group chats only). AI integration is out of scope.

## Requirements Summary

- **Room Types**: Group chats only (no DMs)
- **Privacy**: Private, invite-only rooms
- **Creation**: Any authenticated user can create rooms
- **Roles**: Simple (owner/member)
- **Messages**: Basic text only (no reactions, replies, edits)
- **Presence**: In-memory via WebSocket only (no DB persistence)
- **Read receipts**: Not needed
- **Invitations**: Require acceptance flow
- **Member removal**: Not supported (members can only leave)

### Presence System (Redis-backed)

```typescript
// Redis keys:
// - presence:room:{roomId} -> SET of userIds
// - presence:user:{userId} -> SET of socketIds (tracks all connections)

// Leverage existing RedisService from src/modules/redis/
class ChatPresenceService {
  constructor(private readonly redis: RedisService) {}

  async setUserOnline(userId: string, socketId: string): Promise<void> {
    await this.redis.sadd(`presence:user:${userId}`, socketId);
  }

  async setUserOffline(userId: string, socketId: string): Promise<void> {
    await this.redis.srem(`presence:user:${userId}`, socketId);
    if ((await this.redis.scard(`presence:user:${userId}`)) === 0) {
      // No more connections - user is fully offline
      // Clean up room memberships...
    }
  }

  async joinRoom(roomId: string, userId: string): Promise<void> {
    await this.redis.sadd(`presence:room:${roomId}`, userId);
  }

  async leaveRoom(roomId: string, userId: string): Promise<void> {
    await this.redis.srem(`presence:room:${roomId}`, userId);
  }

  async getOnlineUsers(roomId: string): Promise<string[]> {
    return this.redis.smembers(`presence:room:${roomId}`);
  }
}
```

### Typing Indicators (Redis-backed)

```typescript
// Redis keys:
// - typing:room:{roomId} -> HASH { userId: timestamp }
// Auto-expire entries after 3 seconds (TTL)

class ChatTypingService {
  constructor(private readonly redis: RedisService) {}

  async setTyping(roomId: string, userId: string): Promise<void> {
    const key = `typing:room:${roomId}`;
    await this.redis.hset(key, userId, Date.now());
    await this.redis.expire(key, 3); // Clear after 3s
  }

  async clearTyping(roomId: string, userId: string): Promise<void> {
    await this.redis.hdel(`typing:room:${roomId}`, userId);
  }

  async getTypingUsers(roomId: string): Promise<string[]> {
    return this.redis.hkeys(`typing:room:${roomId}`);
  }
}
```

### Slice 6: Presence System

**Goal**: Show who's online in each room

**Layers**:

- **Redis**:
  - `presence:room:{roomId}` SET - users online in room
  - `presence:user:{userId}` SET - socket IDs for user
- **WebSocket**:
  - Connection: set user online, join all their rooms in presence
  - Disconnect: set user offline, leave rooms, broadcast `user:presence` offline to rooms
  - Join: add to presence set, broadcast `user:presence` online
  - Leave: remove from presence set, broadcast `user:presence` offline
- **Tests**: Integration tests

**Exit Criteria**: Users show online/offline correctly, presence synchronizes across reconnects
