# Voice Features (Speech-to-Text & Text-to-Speech)

### Overview

Add voice input (speech-to-text) and voice output (text-to-speech) capabilities:

- **Voice Input**: Record button in chat input → transcribe to text using OpenAI Whisper
- **Voice Output**: Play button on messages → convert text to speech using OpenAI TTS

### Architecture Decisions

| Decision       | Choice                                                |
| -------------- | ----------------------------------------------------- |
| Voice Provider | OpenAI APIs (Whisper + TTS) via AI SDK                |
| TTS Trigger    | Manual play button on each message                    |
| STT Trigger    | Record button in chat input (shows when empty)        |
| Backend        | New endpoints for transcription and speech generation |
| Audio Storage  | No storage - stream directly (base64 in transit)      |

@Post("speak")
async generateSpeech(

### 11.3 Frontend: Voice Input Button

**File**: `apps/app/src/modules/chat/components/chat-input.tsx`

Logic:

- When textarea is empty: show record button
- When textarea has text: show send button
- On record: use MediaRecorder API to capture audio
- On stop: upload to `/api/chat/transcribe` and populate textarea

```tsx
const [isRecording, setIsRecording] = useState(false);
const [mediaRecorder, setMediaRecorder] = useState<MediaRecorder | null>(null);

const startRecording = async () => {
  const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
  const recorder = new MediaRecorder(stream, { mimeType: "audio/webm" });
  const chunks: Blob[] = [];

  recorder.ondataavailable = (e) => chunks.push(e.data);
  recorder.onstop = async () => {
    const blob = new Blob(chunks, { type: "audio/webm" });
    const formData = new FormData();
    formData.append("audio", blob, "recording.webm");

    const res = await fetch("/api/chat/transcribe", {
      method: "POST",
      body: formData,
    });
    const { text } = await res.json();
    setContent(text);
  };

  recorder.start();
  setMediaRecorder(recorder);
  setIsRecording(true);
};

const stopRecording = () => {
  mediaRecorder?.stop();
  setIsRecording(false);
};
```

### 11.4 Frontend: Text-to-Speech Player

**File**: `apps/app/src/modules/chat/components/message-item.tsx`

Add play button to each message:

- Fetches `/api/chat/speak` with message content
- Returns base64 audio
- Plays via HTMLAudioElement

```tsx
const [isPlaying, setIsPlaying] = useState(false);
const [audioUrl, setAudioUrl] = useState<string | null>(null);

const playAudio = async () => {
  if (audioUrl) {
    playFromCache();
    return;
  }

  const res = await fetch("/api/chat/speak", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ text: message.content }),
  });
  const { audio } = await res.json();

  const url = `data:audio/mpeg;base64,${audio}`;
  setAudioUrl(url);
  const audioEl = new Audio(url);
  audioEl.onended = () => setIsPlaying(false);
  audioEl.play();
  setIsPlaying(true);
};

// In JSX:
<Button variant="ghost" size="sm" onClick={playAudio}>
  {isPlaying ? <PauseIcon /> : <Volume2Icon />}
</Button>;
```

import { z } from "zod";

export const aiVoiceSchemas = {
  speakSchema: z.object({
    text: z.string().min(1).max(4096),
    voice: z

    audio: z.string(), // base64 encoded
  }),
};

export type SpeakInput = z.infer<typeof aiVoiceSchemas.speakSchema>;
export type TranscribeInput = z.infer<typeof aiVoiceSchemas.transcribeSchema>;

### 12.3 Create SDK Client

**New file**: `packages/sdk/src/voice.ts`

```typescript
import { client } from "./client";

export const voiceClient = {
  speak: (input: { text: string; voice?: string }) =>
    client.post("/api/ai/voice/speak", input),

  transcribe: (audioBlob: Blob) => {
    const formData = new FormData();
    formData.append("audio", audioBlob);
    return client.postFormData("/api/ai/voice/transcribe", formData);
  },
};
```
